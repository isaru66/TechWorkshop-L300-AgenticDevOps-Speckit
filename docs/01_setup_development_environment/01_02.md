# Task 02 - Install prerequisite software

## Introduction

{: .warning }
> If you are using a GitHub Codespace, the development environment is already pre-configured and you can skip this task. If you are working on your local machine, you will need to install the necessary software to complete the workshop exercises.

## Description

In this task, you will install the minimum software requirements on your local machine. There are also optional tools for the full workshop experience.

Spring Boot 4.1.x requires **Java 17 or later** and supports **Maven 3.6.3 or later**, according to its [official system requirements](https://github.com/spring-projects/spring-boot/blob/4.1.x/documentation/spring-boot-docs/src/docs/antora/modules/ROOT/pages/system-requirements.adoc). The workshop uses **JDK 21** and **Maven 3.9** to match the devcontainer; Java 21 is the workshop version, not Spring Boot's minimum requirement.

## Success Criteria

- You have installed all minimum required software.
- (Optional) You have installed Docker Desktop or Rancher for the full experience.

## Key Tasks

### 01: Install Java JDK 21

Install a **JDK**, not just a Java runtime, so that you can compile and run the Spring Boot application. Use JDK 21 to match the devcontainer.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

Download and install a JDK 21 distribution for your operating system:

- [Microsoft Build of OpenJDK 21](https://learn.microsoft.com/en-us/java/openjdk/download) (recommended)
- [Eclipse Temurin 21 JDK](https://adoptium.net/temurin/releases/?version=21) (alternative)

On Windows, install Microsoft Build of OpenJDK 21 using:

```powershell
winget install -e --id Microsoft.OpenJDK.21
```

Set `JAVA_HOME` to the JDK installation directory and ensure its `bin` directory is on your `PATH`. Open a new terminal and verify:

```bash
java --version
javac --version
```

Both commands should report version `21.x`.

</details>

### 02: Install Maven 3.9

Maven is used to build and test the Java backend. Use Maven 3.9 to match the devcontainer.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

Download a **Maven 3.9.x binary archive** from the [Apache Maven downloads page](https://maven.apache.org/download.cgi). Extract it and add its `bin` directory to your `PATH`, following the [installation instructions](https://maven.apache.org/install.html).

Open a new terminal and verify:

```bash
mvn --version
```

The output should report Maven `3.9.x` and Java `21.x`. If Maven reports a different Java version, check `JAVA_HOME`.

</details>

### 03: Install Node.js

Use Node.js 22 to match the devcontainer. npm is included with Node.js.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

Download and install **Node.js 22.x** from the [official downloads page](https://nodejs.org/en/download/). Select version 22 explicitly rather than a newer default LTS version.

Alternatively, use a package manager:

On Windows:

```powershell
winget install OpenJS.NodeJS.LTS
```

On macOS:

```bash
brew install node@22
```

On Linux (via NodeSource):

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
```

Verify the installation:

```bash
node --version
npm --version
```

You should see a version number of `v22.x.x` or later.

</details>

### 04: Install Python

Python 3.11 or later is required. Version 3.14 is recommended.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

Download and install Python from the [official downloads page](https://www.python.org/downloads/). Make sure to check the **Add Python to PATH** option during installation on Windows.

On Windows:

```powershell
winget install -e --id Python.Python.3.14
```

On macOS:

```bash
brew install python@3.14
```

On Linux:

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-pip python3-venv
```

Verify the installation:

```bash
python --version
```

On macOS, Linux, or in the Codespace:

```bash
python3 --version
```

Confirm that the version is `3.11.x` or later. If your Linux distribution provides an older version, install a supported Python version before continuing.

</details>

### 05: Install uv and the Spec Kit Specify CLI

uv manages the Specify CLI installation. The devcontainer installs uv and runs the Specify CLI installation automatically through `postCreateCommand`; local users must run it themselves.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

Install uv using the [official installation instructions](https://docs.astral.sh/uv/getting-started/installation/).

On Windows:

```powershell
winget install -e --id astral-sh.uv
```

On macOS:

```bash
brew install uv
```

On Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Open a new terminal and verify:

```bash
uv --version
```

With Git installed and available on your `PATH` from the previous task, install the same Specify CLI release as the devcontainer:

```bash
uv tool install --force specify-cli --from git+https://github.com/github/spec-kit.git@v1.2.6
uv tool update-shell
```

Open a new terminal and verify:

```bash
specify version
```

Installing the CLI does not initialize Spec Kit in your repository. You will initialize your workspace in Exercise 03.

</details>

### 06: Install Visual Studio Code and extensions

Visual Studio Code is the recommended editor for this workshop. Install the same Java, Spring Boot, Copilot, REST, and PostgreSQL extensions as the devcontainer.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

Download and install Visual Studio Code from the [official downloads page](https://code.visualstudio.com/download).

After installation, open VS Code and install the following extensions from the Extensions Marketplace (`Ctrl+Shift+X`):

- **Extension Pack for Java** (`vscjava.vscode-java-pack`)
- **Spring Boot Extension Pack** (`vmware.vscode-boot-dev-pack`)
- **GitHub Copilot** (`GitHub.copilot`)
- **GitHub Copilot Chat** (`GitHub.copilot-chat`)
- **REST Client** (`humao.rest-client`)
- **PostgreSQL** (`ms-ossdata.vscode-pgsql`)

You can also install these extensions from the command line:

```bash
code --install-extension vscjava.vscode-java-pack
code --install-extension vmware.vscode-boot-dev-pack
code --install-extension GitHub.copilot
code --install-extension GitHub.copilot-chat
code --install-extension humao.rest-client
code --install-extension ms-ossdata.vscode-pgsql
```

</details>

### 06: (Optional) Install Docker Desktop or Rancher

Docker Desktop or Rancher Desktop is optional but recommended for running local PostgreSQL with Docker Compose.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

**Docker Desktop:**

Download and install Docker Desktop from the [official website](https://www.docker.com/products/docker-desktop/).

On Windows:

```powershell
winget install -e --id Docker.DockerDesktop
```

On macOS:

```bash
brew install --cask docker
```

**Rancher Desktop (alternative):**

Download and install Rancher Desktop from the [official website](https://rancherdesktop.io/).

On Windows:

```powershell
winget install -e --id suse.RancherDesktop
```

After installation, start Docker Desktop or Rancher Desktop and ensure that the Docker engine is running.

Verify the installation:

```bash
docker --version
docker compose version
docker info
```

Docker Compose should report `v2.x`, and `docker info` should connect to the running engine without errors. PostgreSQL itself is created later using Compose; it is not installed as a devcontainer feature.

</details>

### 08: Verify your GitHub account and Copilot access

A GitHub account is needed for the repository workflow and GitHub Copilot. If you already have an account, verify that you can sign in and have Copilot access.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

If needed, navigate to [GitHub](https://github.com/) and select **Sign up**. Follow the prompts to create a free personal account. Sign in to GitHub Copilot in VS Code and confirm that your account has access.

{: .note }
> You will need a personal GitHub account (not an enterprise managed account) to fork the repository.

</details>

## Introduction

Start with a workspace where you can safely make and review your own changes.

## Description

Obtain the workshop repository using an approved method and open your copy in VS Code. Keep existing work intact.

## Success Criteria

- You can open the workshop files and inspect the repository status.
- You know where your future exercise changes will be made.

## Learning Resources

## Key Tasks

1. Clone or otherwise obtain an approved copy of the repository.
2. Open it in VS Code and inspect the existing files and Git status.
3. Decide how to keep your work separate from other participants.

# Task 02 - Build accessible views

> **Placeholder:** The final layout, copy, and accessibility checks are still to be designed.

## Introduction

An understandable interface helps participants observe the behavior described in the specification.

## Description

Create a simple view for fabricated account information, with generic wording and no customer branding.

## Success Criteria

- The view presents fictional data clearly, including empty and error states.
- Basic keyboard navigation and readable contrast are considered.

## Learning Resources

- [React: describing the UI](https://react.dev/learn/describing-the-ui)
- [W3C accessibility fundamentals](https://www.w3.org/WAI/fundamentals/accessibility-intro/)

## Key Tasks

1. Sketch a small interface based on the agreed user scenarios.
2. Implement semantic labels and states using only generic text and fictional examples.
3. Check keyboard access and visual clarity; review the resulting changes.

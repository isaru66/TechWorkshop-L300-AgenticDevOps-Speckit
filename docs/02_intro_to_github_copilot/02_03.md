# Task 03 - Build the agreed change

## Introduction

Once you understand and approve the plan, hand it to an implementation agent.
Planning and building are separate decisions: selecting Plan mode alone does
not mean the game has been built.

## Description

Use Copilot **Agent** mode to implement the reviewed Copilot Flappy plan in
your workshop working copy.

## Success Criteria

- The standalone game uses the supplied mascot as its player character.
- Copilot reports the changed files, commands run, and any unresolved issues.
- You can start the game locally and open it in a browser.

## Learning Resources

- [Use chat in VS Code](https://code.visualstudio.com/docs/chat/chat-overview)

## Key Tasks

1. From the reviewed plan, select **Start Implementation** if offered.
   Otherwise, switch the chat selector to **Agent**. Keep the plan and mascot
   context in the conversation; if a new chat opens, attach the reviewed plan
   and image again.
2. Submit this implementation prompt:

   ```text
   Implement the approved Copilot Flappy plan now.

   Work only in src/copilot-flappy/. Use the supplied
   media/common/Copilot mascot.png, copying it into the game's local
   assets if needed without modifying the source image.
   Render only the selected mascot pose as the player, not the full sheet.
   Implement all approved controls, states, collision rules, scoring,
   restart behavior, responsive layout, and asset-load error handling.

   Use npm scripts named dev and build. Include a short README with
   setup, run, build, controls, and manual verification instructions.
   Install the declared dependencies and run the production build.
   Report the changed files, exact commands and their outcomes, and
   anything you could not verify. Do not claim browser checks passed
   unless you actually performed them. Do not add unrelated features.
   ```

3. Review requested tool permissions, terminal commands, and edits. Approve
   only actions you understand; stop and clarify if Copilot proposes unrelated
   changes or external services.
4. Check Copilot's completion report. If the build failed, ask it to fix the
   reported error and rerun the build before continuing.
5. In a terminal, start the game from the repository root:

   ```shell
   cd src/copilot-flappy
   npm run dev -- --host 127.0.0.1
   ```

   Open the local URL printed by Vite. In GitHub Codespaces, use
   `npm run dev -- --host 0.0.0.0` instead, open the forwarded port from the
   **Ports** panel, and keep its visibility **Private**. Stop the server with
   **Ctrl+C** when finished.

If dependencies have not been installed, run `npm install` in the game folder
before starting the server. A successful build is not proof that the game is
playable: continue to [Task 04 - Review the result](02_04.md).

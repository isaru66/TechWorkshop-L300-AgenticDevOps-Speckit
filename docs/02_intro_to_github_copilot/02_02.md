# Task 02 - Plan with Copilot

## Introduction

Plan mode helps turn a game idea into an implementation approach before code
is changed. Review the plan rather than accepting the first proposal automatically.

## Description

Use **Plan** in Copilot Chat to plan Copilot Flappy. Keep the mascot image
attached as context.

## Success Criteria

- The plan covers game behavior, files, mascot handling, and verification.
- You have resolved important assumptions and approved the scope.
- No game implementation has started.

## Learning Resources

- [Plan work with agents in VS Code](https://code.visualstudio.com/docs/agents/run/planning)

## Key Tasks

1. Select **Plan** in the Copilot Chat mode or agent selector.
2. Attach the mascot image from Task 01 and submit this prompt:

   ```text
   Plan a small Flappy Bird-style browser game called Copilot Flappy.
   Do not implement it yet.

   Use HTML, CSS, JavaScript, and Vite with no backend, accounts,
   external APIs, or runtime CDN dependencies. Put the standalone game
   in src/copilot-flappy/ without changing the banking application.

   Use media/common/Copilot mascot.png as the main player character.
   It contains multiple poses. Plan how to crop one pose into a local
   sprite or render a source rectangle, preserving its aspect ratio.
   Do not show the entire sheet, stretch the mascot, or substitute an emoji.
   Account for the image's flat background and whitespace so the character
   looks intentional and its collision box matches its visible body.
   Keep the supplied source image unchanged.
   ```

3. Answer Copilot's clarifying questions and review the plan:
4. If something is missing, refine the plan before approving it. 

Your expected output is a reviewed plan, not game source code.

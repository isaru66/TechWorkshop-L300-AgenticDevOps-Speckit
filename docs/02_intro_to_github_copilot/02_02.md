## Introduction

## Description

Use Copilot Plan mode for the fictional task, then review and refine the proposed approach.

## Success Criteria

- A plan identifies the goal, assumptions, and checks for the task.
- You have reviewed the plan before allowing implementation.

## Learning Resources

## Key Tasks

1. Select the available Copilot Plan mode or Plan agent and request an approach.
2. Clarify assumptions and ask for small, testable steps.
3. Review the plan and choose an acceptable scope before building.

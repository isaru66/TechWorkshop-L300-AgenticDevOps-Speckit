## Introduction

Review follows the build; generated changes are not automatically correct or safe.

## Description

Inspect the change against the plan, run appropriate checks, and resolve or record any issues.

## Success Criteria

- You can explain the change and its verification results.
- Deviations or unresolved issues are identified rather than silently accepted.

## Learning Resources

- [Review AI-generated code edits in VS Code](https://code.visualstudio.com/docs/agents/run/review-code-edits)
- [Review changes in Git](https://git-scm.com/docs/git-diff)

## Key Tasks

1. Review the diff against the goal and agreed plan.
2. Run the relevant checks and inspect their results.
3. Correct problems or document what remains before starting another cycle.

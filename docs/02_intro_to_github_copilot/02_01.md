# Task 01 - Explore GitHub Copilot

> **Placeholder:** This is an overview, not a complete Copilot tutorial.

## Introduction

GitHub Copilot can help explore a problem, propose changes, and assist with verification; participants remain responsible for the outcome.

## Description

Inspect the chat experience and identify what context an assistant needs for a small fictional example.

## Success Criteria

- You can explain the roles of the participant and the assistant.
- You can describe why prompts and context should contain no secrets or real customer data.

## Learning Resources

- [Build with AI in VS Code](https://code.visualstudio.com/docs/agents/overview)
- [Responsible use of GitHub Copilot](https://docs.github.com/en/copilot/responsible-use-of-github-copilot-features)

## Key Tasks

1. Open Copilot chat and inspect the available interaction options.
2. Describe a small fictional task without asking for implementation yet.
3. Identify the context that is safe and necessary to share.

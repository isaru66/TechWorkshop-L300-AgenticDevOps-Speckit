# Task 01 - Explore GitHub Copilot

## Introduction

GitHub Copilot can help explore a problem, plan an implementation, and build
and check code. You remain responsible for choosing the scope, approving
changes, and verifying the result.

## Description

Prepare the context for **Copilot Flappy**, a Flappy Bird-style game in which
the supplied Copilot mascot replaces the bird.

![Copilot mascot poses for the player character](../../media/common/Copilot%20mascot.png)

The supplied image contains several poses, not one ready-to-use player sprite.
The plan must explain how to isolate one pose so the game does not display
the whole sheet as its character.

## Success Criteria

- Copilot Chat is open and you can locate the mode selector.
- You have located the mascot image and can add it as chat context.
- You can explain the game requirements without asking for implementation yet.

## Learning Resources

- [Build with AI in VS Code](https://code.visualstudio.com/docs/agents/overview)
- [Responsible use of GitHub Copilot](https://docs.github.com/en/copilot/responsible-use-of-github-copilot-features)

## Key Tasks

1. Open this workshop repository in VS Code and open **Copilot Chat**.
2. Locate the mode or agent selector. Identify **Plan** for planning and
   **Agent** for implementation. If either is missing, check that VS Code and
   GitHub Copilot are up to date and that your account has access.
3. Open `media/common/Copilot mascot.png`. Add it to chat using **Add Context**
   or drag the image into the chat input. If your client does not support image
   attachments, provide its workspace path and ask Copilot to inspect the file.
4. Agree on the following scope before moving to Plan mode:

   | Area | Requirement |
   | --- | --- |
   | Player | One isolated Copilot mascot pose from the supplied image |
   | Controls | Space, click, or tap to flap upward; gravity pulls downward |
   | Obstacles | Scrolling pairs with randomized, reachable gaps |
   | Score | One point for each obstacle pair passed |
   | States | Ready, playing, and game over, with an explicit restart action |
   | Presentation | Visible instructions and score; usable on desktop and mobile |
   | Technology | HTML, CSS, JavaScript, and Vite; no backend or external services |
   | Location | A new `src/copilot-flappy/` folder, separate from the banking app |

Only share workshop assets and fictional examples. Never attach credentials,
customer data, or production configuration.

Continue to [Task 02 - Plan with Copilot](02_02.md). Do not ask Copilot to
create the game files yet.

# Task 02 - Adapt a PPTX skill to a sample style

> **Placeholder:** This fictional style brief is generic guidance, not a real customer's brand.

## Introduction

A skill can include presentation guidance while remaining reusable and free of customer-specific materials.

## Description

Adapt a copy of an approved PPTX skill to a generic sample customer-style brief. Do not use real customer names, logos, templates, or proprietary assets.

## Success Criteria

- The copied skill includes clear, generic presentation guidance.
- The original skill and its license are respected, and no sensitive material is added.

## Learning Resources

- [Create and use agent skills](https://code.visualstudio.com/docs/agent-customization/agent-skills)
- [Agent Skills specification](https://agentskills.io/specification)

## Key Tasks

1. Use Copilot Plan mode to review the skill's source, license, and proposed adaptations before making a participant-owned copy.
2. Build the change by adapting its instructions to this sample brief: uncluttered layouts, consistent readable typography, a neutral background with one restrained accent, and short fictional slide text.
3. Review the modified instructions for accessibility, generic wording, and absence of logos or customer-specific assets.

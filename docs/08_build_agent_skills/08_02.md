# Task 02 - Create the blue-brand-pptx skill

## Introduction

Improve a copy of the installed skill so the original `pptx` remains available as a baseline.

## Description

Copy `.agents/skills/pptx` to `.agents/skills/blue-brand-pptx`, retain its generation and validation capabilities, and give the copy a distinct name and discovery description.

## Success Criteria

- The new folder is an independent copy, not a link back to the original.
- Its `SKILL.md` frontmatter names the skill `blue-brand-pptx` and explains when to use it.
- The original skill is unchanged, and applicable license notices are preserved.

## Learning Resources

- [Create and use agent skills](https://code.visualstudio.com/docs/agent-customization/agent-skills)
- [Agent Skills specification](https://agentskills.io/specification)

## Key Tasks

1. In Copilot Plan mode, review the copy and customization approach:

   ```text
   Help me create a skill called "blue-brand-pptx".
   Plan to copy the complete .agents/skills/pptx folder into
   .agents/skills/blue-brand-pptx, preserving scripts, references,
   license notices, and the original skill unchanged.
   Check for an existing destination and do not overwrite it.
   The copy will use a customer-provided sample PDF for its brand style.
   Identify which instructions and paths need updating. Do not edit yet.
   ```

2. Approve the plan, then switch to Agent mode to make the independent copy. If the destination already exists, review it and decide whether to reuse it before making changes.
3. Update the copied `SKILL.md` frontmatter, retaining any other required fields:

   ```yaml
   ---
   name: blue-brand-pptx
   description: "Create and edit blue-brand PowerPoint presentations using the approved PDF-derived style guide and bundled icons/images. Use when asked for blue-brand slides, branded decks, or blue-brand-pptx."
   ---
   ```

4. Keep the original creation, editing, rendering, and quality-check workflows. Update references that incorrectly point back to the original skill; keep internal resource links relative to the copied skill.
5. Add a brand-preparation step: read `references/brand-style.md` and use approved files from `assets/` once Task 03 creates them. If the PDF or style guide is missing, request the reference instead of inventing a customer style.
6. Inspect the changes and confirm no files under `.agents/skills/pptx` were modified.

The name `blue-brand-pptx` identifies the new skill; the supplied PDF, not assumptions about that name, determines its actual colors and visual rules.

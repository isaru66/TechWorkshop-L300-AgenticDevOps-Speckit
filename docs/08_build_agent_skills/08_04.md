# Task 04 - Iterate and share the skill

> **Placeholder:** Define the final review and approved sharing process before delivery.

## Introduction

Review findings help improve the skill; sharing should preserve only safe, reusable guidance.

## Description

Refine the copied skill based on the test and prepare it for sharing through an approved channel.

## Success Criteria

- The revised skill addresses at least one observed issue and is retested.
- The proposed shared material contains no secrets, real customer information, or unlicensed assets.

## Learning Resources

- [Agent skills in VS Code](https://code.visualstudio.com/docs/agent-customization/agent-skills)
- [Agent Skills specification](https://agentskills.io/specification)

## Key Tasks

1. Update the skill instructions to address a concrete test finding.
2. Rerun a fictional test and review the differences.
3. Check licensing and content, then share only the approved, non-sensitive skill material.

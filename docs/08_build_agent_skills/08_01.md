# Task 01 - Get the PPTX skill from skills.sh

## Introduction

Agent skills package task-specific instructions in `SKILL.md`, together with supporting scripts, references, and assets. Start with an existing presentation skill rather than writing a presentation generator from scratch.

## Description

Find the `pptx` skill on [skills.sh](https://skills.sh/), review its source and license, and install it into the participant workspace.

## Success Criteria

- `.agents/skills/pptx/SKILL.md` exists in the workspace.
- You have reviewed the skill's instructions, dependencies, scripts, and license before executing them.
- Copilot can discover the installed skill.

## Learning Resources

- [Agent skills in VS Code](https://code.visualstudio.com/docs/agent-customization/agent-skills)
- [PPTX skill on skills.sh](https://skills.sh/anthropics/skills/pptx)
- [Skills CLI reference](https://skills.sh/docs/cli)

## Key Tasks

1. Open skills.sh, search for `pptx`, and inspect the `anthropics/skills` result. Review the upstream source and license; proceed only if adaptation is permitted for your intended use.
2. From the participant workspace root, install only that skill:

   ```text
   npx skills add anthropics/skills --skill pptx
   ```

3. In the installer, choose project scope rather than global scope, enable GitHub Copilot, and use the shared `.agents/skills` location. Review the destination in the installer summary; do not assume installation succeeded at the intended path.
4. In VS Code Explorer, confirm `.agents/skills/pptx/SKILL.md` exists. If the installer used another supported location, resolve that before continuing: this exercise uses `.agents/skills/pptx` as its source.
5. Read `SKILL.md` and the referenced generation and validation instructions. Check dependencies and install only what the selected workflow needs, using the documented environment.
6. Ask Copilot to inspect the installed skill without generating a presentation:

   ```text
   Inspect .agents/skills/pptx/SKILL.md and its referenced files.
   Explain what this skill does, its prerequisites, and how to generate
   and visually validate a presentation. Do not change any files yet.
   ```

If Copilot does not discover the skill, confirm agent skills are enabled and consult the VS Code documentation before proceeding.

# Task 03 - Extract the PDF style and assets

## Introduction

A reference PDF can demonstrate a visual system: colors, typography, layouts, imagery, and icon treatments. Package that system inside the copied skill so future presentations can reuse it.

## Description

Use **`<customer to provide sample PDF>`** as the reference. Extract its style and approved reusable icons/images into `.agents/skills/blue-brand-pptx`. Do not substitute an invented brand or claim extraction is complete before the PDF is supplied.

## Success Criteria

- `references/brand-style.md` records observed style rules with PDF page references.
- Extracted icons/images are stored in the new skill's `assets/` folder and can be opened.
- The skill links to its style guide and assets with relative paths.
- Reuse permissions and any extraction limitations are documented.

## Learning Resources

- [Agent skills in VS Code](https://code.visualstudio.com/docs/agent-customization/agent-skills)
- [Agent Skills specification](https://agentskills.io/specification)

## Key Tasks

1. Request the customer sample PDF and confirm permission to process and reuse its design and selected assets in the approved environment. Do not attach confidential material to an unapproved AI service.
2. Place the approved PDF in a participant-local reference location. If it has not been supplied, pause this task and the branded test.
3. Use Copilot Plan mode to identify available PDF inspection/extraction tools and review the proposed output. Then approve execution in Agent mode:

   ```text
   Improve .agents/skills/blue-brand-pptx using this reference:
   <customer to provide sample PDF; replace with the approved local path>.

   Inspect representative PDF pages visually as well as their text.
   Extract the observed palette (hex values), typography and hierarchy,
   backgrounds, spacing, title/body layouts, chart/table styling,
   footers, and icon/image treatments.

   Save the style guide to references/brand-style.md inside the new skill.
   Distinguish observed rules from inferred guidance and include source
   page numbers. Flag fonts or details that cannot be reliably identified.

   Extract approved reusable icons and images into assets/icons/ and
   assets/images/ inside the new skill. Preserve usable quality,
   transparency, and aspect ratios. Do not copy customer text or data.
   If a graphic is flattened or cannot be extracted independently,
   report that limitation and request an approved source asset.

   Create assets/README.md listing each extracted file, source PDF page,
   intended use, and confirmed reuse restrictions. Update SKILL.md to
   reference the style guide and asset inventory with relative links.
   Do not modify .agents/skills/pptx or publish customer materials.
   ```

4. Compare the style guide with the PDF. Approve any inferred spacing, font substitutions, or other approximations explicitly.
5. Open every extracted asset. Check resolution, transparency, cropping, and whether it is genuinely reusable rather than an entire page screenshot.
6. Confirm the new skill contains the following additions:

   ```text
   .agents/skills/blue-brand-pptx/
     SKILL.md
     references/
       brand-style.md
     assets/
       README.md
       icons/
       images/
   ```

Keep the copied base skill's other scripts and references. Include only approved materials; do not commit the reference PDF or extracted customer assets to the public workshop repository.

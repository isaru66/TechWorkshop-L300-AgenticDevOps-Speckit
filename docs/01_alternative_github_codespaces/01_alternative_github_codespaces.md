# Exercise 01 Alternative: Use GitHub Codespaces

Use GitHub Codespaces instead of installing the development tools locally. Fork the workshop repository with your personal GitHub account, then create a Codespace from your fork.

## Tasks

1. [Set up GitHub Codespaces](./01A01.md) - fork the repository, create a Codespace, and verify the workspace.
2. [Use your enterprise account for Copilot Chat](./01A02.md) - switch Copilot Chat to your organization's account and verify the selected account.

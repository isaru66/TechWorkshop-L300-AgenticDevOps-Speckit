# Application workspace

This directory contains placeholders for the application attendees will create
and the existing fictional seed data. Through Exercise 04, choose a Java
Spring Boot or ASP.NET Core 10 (.NET 10) REST backend. Both paths use a React
frontend and PostgreSQL.

- [`backend/`](backend/README.md) is reserved for the backend.
- [`frontend/`](frontend/README.md) is reserved for the frontend.
- [`data/seed/`](data/seed/README.md) contains four tracked fictional CSV files.

There is no application source, runnable service, database, Compose
configuration, or initialized Spec Kit project here yet. Attendees create
those pieces and plan the seed import. Later Exercises 05-07 are Java/MCP-oriented
scaffolding, not a completed .NET continuation.

Use only fictional data in a private, trusted development environment. The
intended application has no application authentication and must not be
exposed publicly. See the [root README](../README.md) for prerequisites and
the full safety warning.

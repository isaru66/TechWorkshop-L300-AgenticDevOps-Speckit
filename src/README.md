# Fictional banking application

This workshop implementation provides a React interface, an ASP.NET Core 10
controller API, and local PostgreSQL. It uses only the supplied fictional CSV
data and has no login or customer/account maintenance.

- [`backend`](backend/README.md): API, import, and integration tests.
- [`frontend`](frontend/README.md): blue-and-white React interface.
- [`data/seed`](data/seed/README.md): the original fictional baseline.
- [Quickstart](../specs/001-local-banking-api/quickstart.md): prerequisites,
  configuration, build, import, startup, tests, and REST/UI verification.

Keep all services and forwarded ports private; do not use real financial data.

# Application workspace

This directory is a placeholder for the application attendees will create
during the workshop. The intended demo uses a Java Spring Boot backend with
REST and MCP interfaces, a React frontend, and PostgreSQL.

- [`backend/`](backend/README.md) is reserved for the backend.
- [`frontend/`](frontend/README.md) is reserved for the frontend.
- [`data/seed/`](data/seed/README.md) is reserved for attendee-created CSV data.

There is no application source, runnable service, sample data, Compose
configuration, or initialized Spec Kit project here yet. Follow the relevant
exercise when it is available to create those pieces.

Use only fictional data in a private, trusted development environment. The
intended application has no application authentication and must not be
exposed publicly. See the [root README](../README.md) for prerequisites and
the full safety warning.

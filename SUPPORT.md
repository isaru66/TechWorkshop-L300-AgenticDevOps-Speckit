# Support

Start with the [README](README.md), [workshop home](index.md), and relevant
[documentation](docs/). Check the exercise instructions and prerequisites
for your environment before requesting help.

If GitHub Issues are available for this repository, search existing issues
and open one if you still need help. Include the exercise, repository
revision, relevant tool versions, what you expected, what happened, and
minimal steps to reproduce it. Sanitize logs and screenshots: do not include
credentials, tokens, real personal or financial data, or other sensitive
information. Support is provided on a best-effort basis.

For a security concern, follow [SECURITY.md](SECURITY.md) instead of posting
vulnerability details publicly.
